> **面向 AI 代理的工作者：** 必需子技能：使用 subagent-driven-development（推荐）或 executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 在动业务代码之前先建立格式、CI 与覆盖率守卫，并清掉两处死代码，使后续六个阶段的每个改动都有自动回归。

**技术栈：** Biome 2、GitHub Actions、`bun test --coverage`。

**规格：** `docs/superpowers/plans/2026-10-18-optimization-roadmap.md`（全局约束与审查重点对每个任务都生效）。

- [ ] **步骤 2：把配置改成仓库现有风格，且只做格式不做 lint**


### 任务 2：CI + 覆盖率门槛

**文件：**
- 创建：`.github/workflows/ci.yml`、`bunfig.toml`
- 修改：`package.json`

- [ ] **步骤 1：先量出基线覆盖率**

运行：`bun test --coverage`
预期：输出 `File | % Funcs | % Lines` 表格。记下全仓 `All files` 的 `% Lines`（记为 `L`）与 `% Funcs`（记为 `F`）。

- [ ] **步骤 2：写 `bunfig.toml`，阈值取基线向下取整再减 2 个百分点**

```toml
[test]
coverageThreshold = 0.75
coverageSkipTestFiles = true
```

把 `0.75` 替换成 `floor(min(L, F) * 100 - 2) / 100` 的实际值（例如基线 84% → 写成 0.82）。门槛只许升不许降；后续阶段补充测试后可上调。

- [ ] **步骤 3：验证门槛生效**

运行：`bun run test:coverage`
预期：末尾打印覆盖率表且退出码 0（`echo $?` 为 `0`）。

- [ ] **步骤 4：写 CI workflow**

`.github/workflows/ci.yml`：

```yaml
name: ci
on: [push, pull_request]

jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: oven-sh/setup-bun@v2
        with: { bun-version: latest }
      - run: bun install --frozen-lockfile
      - run: bun run lint
      - run: bun run typecheck
      - run: bun run test:coverage

  postgres:
    runs-on: ubuntu-latest
    services:
      postgres:
        image: postgres:16
        env:
          POSTGRES_PASSWORD: pg
          POSTGRES_DB: wl
        ports: ["5432:5432"]
        options: >-
          --health-cmd pg_isready --health-interval 10s
          --health-timeout 5s --health-retries 5
    env:
      DB_PROVIDER: postgres
      DATABASE_URL: postgres://postgres:pg@localhost:5432/wl
    steps:
      - uses: actions/checkout@v4
      - uses: oven-sh/setup-bun@v2
        with: { bun-version: latest }
      - run: bun install --frozen-lockfile
      - run: bun test tests/integration
```

- [ ] **步骤 5：本地验证 workflow 里的每条命令**

运行：`bun install --frozen-lockfile && bun run lint && bun run typecheck && bun run test:coverage`
预期：三条命令依次成功，无 error 输出。

- [ ] **步骤 6：远程验证（推送后）**

推一个临时分支并开 PR，确认 `ci / test` 与 `ci / postgres` 两个 job 都绿；然后删除该分支。
预期：两个 job 均为绿色勾。

- [ ] **步骤 7：Commit**

```bash
git add .github bunfig.toml package.json
git commit -m "ci: 增加 typecheck/格式/覆盖率与 Postgres 双跑流水线"
```
