# 阶段 03：安全加固 实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 subagent-driven-development（推荐）或 executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 补齐响应头与 CSP、管理写操作的跨站防护、历史读取限流、生产口令策略、IP 严格校验，并把页面渲染结果缓存掉（顺带完成 B9）。

**架构：** 安全头放在 `app.ts` 的全局中间件；CSP 由 `pages.ts` 对渲染后的内联 `<script>/<style>` 求 sha256 生成（零构建不变，不用 `unsafe-inline`）；管理写操作的 Origin 校验独立挂 `/api/admin/*`，与公开 API 的 allowlist 解耦。

**技术栈：** `node:crypto`（`createHash`/`timingSafeEqual`）、`node:net`（`isIP`）、Hono 中间件。

**规格：** `docs/superpowers/plans/2026-10-18-optimization-roadmap.md`（全局约束与审查重点对每个任务都生效）。

## 全局约束

- 新增 env 变量必须同时出现在 `.env.example` 与 README 变量表。
- `adminRequireOrigin` 默认值：生产 `true`，其他环境 `false`；`tests/helpers.ts` 的 `testCfg` 必须显式写 `false`，否则既有 admin 测试会因缺少 Origin 全灭。
- 任何安全头都不得破坏 `public/*.html` 的现有内联脚本与样式（用 CSP hash，不用 `unsafe-inline`）。

- [ ] **步骤 4：`pages.ts` 加 CSP 与缓存**

```ts
import { createHash } from "node:crypto";

type Rendered = { html: string; csp: string };
const cache = new Map<string, Rendered>();
const stats = { hits: 0, misses: 0 };

/** 内联块 → 'sha256-…'；零构建页面靠 hash 过 CSP，不用 unsafe-inline。 */
const inlineHashes = (html: string, tag: "script" | "style"): string[] =>
  [...html.matchAll(new RegExp(`<${tag}>([\\s\\S]*?)</${tag}>`, "g"))].map(
    (m) => `'sha256-${createHash("sha256").update(m[1]).digest("base64")}'`,
  );

export function cspFor(html: string): string {
  const script = inlineHashes(html, "script");
  const style = inlineHashes(html, "style");
  return [
    "default-src 'self'",
    ["script-src 'self'", ...script].join(" "),
    ["style-src 'self'", ...style].join(" "),
    "connect-src 'self'",
    "img-src 'self' data:",
    "base-uri 'none'",
    "form-action 'none'",
    "frame-ancestors 'none'",
  ].join("; ");
}

export function clearPageCache(): void { cache.clear(); stats.hits = 0; stats.misses = 0; }
export function pageCacheStats(): { hits: number; misses: number } { return { ...stats }; }
```

`serve` 改为：

```ts
const serve = async (c: Context<AppEnv>, file: string) => {
  c.header("cache-control", PAGE_CACHE);
  try {
    let r = cache.get(file);
    if (r) stats.hits += 1;
    else {
      stats.misses += 1;
      const html = renderPage(await readPublic(file));
      r = { html, csp: cspFor(html) };
      cache.set(file, r);
    }
    c.header("content-security-policy", r.csp);
    return c.html(r.html);
  } catch {
    return c.body(fill(COPY.route.pageMissing, { file }), 404);
  }
};
```

```ts
import { isIP } from "node:net";
import { createHash, timingSafeEqual } from "node:crypto";

const V4_MAPPED = /^::ffff:(\d{1,3}(?:\.\d{1,3}){3})$/i;

export function normalizeIp(raw: string): string | null {
  const v = raw.trim();
  if (!v) return null;
  const mapped = V4_MAPPED.exec(v);
  const cand = mapped ? mapped[1] : v;
  const kind = isIP(cand);
  if (kind === 4) return cand;
  if (kind === 6) return cand.toLowerCase();
  return null;
}

/** 摘要后再比较：长度不同也不泄露，且代价恒定。 */
export function constantTimeEqual(a: string, b: string): boolean {
  const ha = createHash("sha256").update(a).digest();
  const hb = createHash("sha256").update(b).digest();
  return timingSafeEqual(ha, hb);
}
```

```ts
app.use("/api/admin/*", async (c, next) => {
  if (!cfg.adminRequireOrigin) return next();
  const m = c.req.method;
  if (m === "GET" || m === "HEAD" || m === "OPTIONS") return next();
  const origin = c.req.header("origin");
  if (!origin) return jsonError(c, 403, "missing_origin");
  const host = c.req.header("x-forwarded-host") ?? c.req.header("host") ?? "";
  const proto = (c.req.header("x-forwarded-proto") ?? new URL(c.req.url).protocol.replace(":", "")).toLowerCase();
  const expected = normalizeOrigin(`${proto}://${host}`);
  if (normalizeOrigin(origin) !== expected)
    return jsonError(c, 403, "origin_not_allowed", { origin: normalizeOrigin(origin).slice(0, 256) });
  await next();
});
```

注意：这里**故意**不看 `ALLOWED_ORIGINS`——跨站 allowlist 是给公开 API 的，不应该顺带授权删库。
