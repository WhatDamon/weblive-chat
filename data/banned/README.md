# 违禁词词库

本目录存放内置违禁词表，由 `src/lib/wordfilter.ts` 装载，`BANNED_WORDS_MODE` 控制启用范围。

## 目录结构

| 目录 | 何时加载 | 内容 |
|---|---|---|
| `basic/` | `BANNED_WORDS_MODE=basic`（默认）与 `strict` | 高精度精选词表（色情/辱骂/涉枪涉爆/诈骗广告） |
| `strict/` | 仅 `BANNED_WORDS_MODE=strict` | 扩展词表，**默认不随仓库分发**（见 `strict/README.md`） |

## 精选规则（为什么不直接整包导入）

源词库面向「文本审核」，直接拿来拦聊天会大面积误伤。本目录按以下规则裁剪：

1. **剔除正常语境词**：`广告类型.txt` 含「兼职 / 招聘 / 网络 / QQ / 客服 / 到货 / 本店」，`色情词库.txt` 含「按摩 / 刺激 / 少妇 / 自拍 / 人妻」——这些在正常聊天里天天出现
2. **词长下限 2**：单字词（如「屌」）会让「操场」「胡萝卜」这类正常文本误命中
3. **丢弃过短纯 ASCII 词**：`av` / `sm` / `3p` 会命中 `have` / `small` 等正常英文单词
4. **政治/暴恐类默认不启用**：是否按大陆口径审核属部署方的合规判断，见 `strict/`

## 匹配语义

- 匹配在**归一化文本**上进行：NFKC（全角转半角）、英文小写、剔除零宽字符/空白/标点/符号。
  因此「赌　博」「赌 博」「赌\*博」「赌​博」都会被同一词条命中
- 命中即拒收，客户端只收到「内容含违禁词」，**不回显命中的词**（否则等于对外提供绕过字典）
- 昵称与消息内容都受检

## 增删与误伤处理

- 直接编辑 `basic/*.txt`：每行一个词条，`#` 开头为注释，空行忽略
- 或用环境变量：`BANNED_WORDS`（追加显式词）、`BANNED_WORDS_ALLOW`（白名单，命中区间被其覆盖时豁免）、`BANNED_WORDS_DIR`（改词库目录）
- 误伤处理顺序：先把正常表达加入 `BANNED_WORDS_ALLOW`（改环境变量即时生效），再从词库文件删掉该词条
- 新增词条请避免 2 字常用组合（如「兼职」「客服」），否则会拦截大量正常发言
